# TraceLens for TDP 架构与边界

## 数据流

浏览器 → 本机 Python HTTP 服务 → TDP HTTPS 开放接口。

本机服务在每次请求时生成秒级时间戳，以 `ApiKey + Timestamp` 为签名串，使用 Secret 做 HMAC-SHA256，再 URL-safe Base64 编码并移除填充。API Key、时间戳与签名通过查询参数发送，Secret 不发送。请求仅允许三个已知的只读接口，不提供通用 URL 代理。

业务成功要求 HTTP 成功且 `response_code` 为 0。错误只返回受控提示，不返回包含签名的完整 URL 或远端原始错误。网络超时 30 秒，响应体最多 8 MB，不跟随重定向。

## 调查模型

每份 case 有数据来源、目标 IP、人工状态、备注及不可覆盖的 evidence snapshots。

1. 规范化 IP，拒绝任意 SQL 输入。
2. 通过固定字段构建 IP 查询表达式。
3. 校验返回记录的目标和时间范围；不匹配记录剔除并提示。
4. 按时间和原始 ID 排序，基于完整记录去重，分配快照内 `E001` 证据编号。
5. 生成规则辅助判断；不把事件数量转换成虚构置信度或“失陷概率”。
6. SQLite 事务保存，备注与快照追加使用事务避免并发覆盖。

引用编号只在同一个快照内有效。报告默认导出最新快照；历史快照保留可查。复查要求后续窗口和相同 TDP 根地址，保存原始快照并说明不可直接比较总量。

## 可选模型分析

每次分析绑定快照 ID 和已配置模型目的地址。预览后若快照变化，要求重新确认。只发送前 100 条证据摘要；不发送 TDP 密钥、完整原始记录、资产个人字段或人工备注。

模型输入中的日志为不可信数据。系统提示要求不执行日志内指令，并区分事实与假设。模型没有任何写操作或工具权限。输出按文本转义展示，检查无效证据引用，但不宣称完成语义事实核验。

## 本机访问边界

- 固定监听 `127.0.0.1`，首版不支持远程或多人访问。
- Host 仅接受 `127.0.0.1:port` 与 `localhost:port`，降低 DNS rebinding 风险。
- 拒绝跨 Origin 和跨站 Fetch Metadata 请求；业务 API 使用进程随机 token。
- 不添加跨域许可头；CSP 限制同源脚本和网络，禁止 iframe 嵌入。
- 静态文件采用显式白名单，不提供目录遍历或配置下载。
- 页面中来自 API 的内容统一转义，不插入原始 HTML。
- 仅防范其他网页跨站访问，不防范当前用户权限下的恶意本机进程。

## 尚未覆盖的部署能力

团队身份认证、角色授权、凭据加密托管、集中审计、数据保留策略、后台调度和生产部署限流尚未提供。不要把该本机服务直接暴露到公网。Python 标准库 HTTP 服务用于本地工作台，不作为公网生产服务器。
