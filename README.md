# TraceLens for TDP · 威胁透镜

面向 ThreatBook TDP 的 AI 威胁调查工作台，让每个判断都有证据可循。

> 本项目为独立开发的非官方项目，不代表 ThreatBook 官方产品，也未声明获得其背书。ThreatBook 与 TDP 名称仅用于说明产品兼容目标。

## 项目状态

项目初始化阶段，尚未发布可运行版本。

## 规划方向

- 围绕单台主机展开调查，关联告警、资产与日志。
- 通过证据时间线展示调查过程，区分事实、推测和证据缺口。
- 支持人工复核与处置后的风险复查。

## 连接配置

使用者自行配置 TDP 地址、API Key 和 Secret。真实凭据仅保存在使用者本地或部署服务端，不提交到仓库。

仓库不包含实际测试环境地址、API 凭据或真实告警数据。后续将提供空白配置模板，并通过 Git 忽略规则排除真实配置。
